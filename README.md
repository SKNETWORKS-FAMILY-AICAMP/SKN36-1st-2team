# 🚚 WAYLOGI

전국 **자동차 등록 데이터와 인구 데이터**를 활용하여
지역별 물류 입지 적합도를 분석하고 추천하는 서비스입니다.

## 📌 프로젝트 소개

WAYLOGI는 물류·운송·화물 관련 기업의 입지 선정을 돕기 위해
지역별 데이터를 분석하여 **물류 거점 점수**와 **지역 특성 분석 결과**를 제공합니다.

## 📊 주요 데이터

* 전국 자동차 등록 현황
* 지역별 화물차 등록 현황
* 지역별 인구 데이터
* 행정구역 코드 데이터
* 2023.07 ~ 2026.07 월별 데이터

## ⭐ 주요 기능

* 지역별 자동차 및 화물차 등록 현황 조회
* 지역별 데이터 시계열 분석
* 물류 거점 점수 산출

  * **산업성** : 물류 활동이 활발한 지역인가?
  * **성장성** : 성장하고 있는 지역인가?
  * **수요성** : 충분한 수요가 존재하는 지역인가?
* 지역별 물류 입지 특성 분석
* 지도 기반 지역 검색 및 결과 시각화
